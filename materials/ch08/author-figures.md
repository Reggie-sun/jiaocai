## 图8-1 从外部变化到个人学习行动的判断路径

- **Marker and placement:** `<!-- FIGURE:8-1 -->`; after 8.1.4 and before E01.
- **Purpose:** show why a technology headline or employer forecast is a signal to investigate rather than an automatic personal learning mandate.
- **Visual form:** left-to-right decision flow with a visible branch and return loop. Use five main rounded rectangles: “外部信号（报告 / 岗位 / 项目）” → “确认情境（样本、地区、时间、版本）” → “描述具体任务变化” → “诊断当前表现与学习缺口” → “选择小型练习并检查证据”. From the context box, a branch “信息不足” points to “待核实：补查原始材料”, then returns to the signal/context step. From the evidence box, a branch “未达到标准” returns to “诊断当前表现与学习缺口”; “达到本轮标准” points to “复盘下一目标”.
- **Data and relations:** no quantitative data. Use line style to distinguish known evidence from pending investigation; arrows mean a reasoning dependency, not causal proof that every technology signal changes an individual job.
- **Source and limits:** author-created synthesis of Section 8.1’s distinction between forecasts, local adoption, task change and personal gap. WEF [1] is a cited example of employer outlook evidence, not a source for all boxes.
- **Textbook reading guide:** already in manuscript; readers begin at the signal and follow the “待核实” branch when context is missing.
- **Accessibility:** provide alt text describing the left-to-right path and the two return branches; do not rely on color alone.

## 图8-2 一次学习如何连接讲解、延迟提取与应用

- **Marker and placement:** `<!-- FIGURE:8-2 -->`; after 8.2.3 and before 8.2.4.
- **Purpose:** distinguish initial study, closed-material retrieval, feedback and transfer practice; avoid portraying “more rereading” as the only next action.
- **Visual form:** horizontal timeline with four distinct activity panels: “理解材料并提出问题” → “合上材料，先提取” → “核对来源并修正” → “换条件应用并解释”. Under the timeline, use a return arrow from “错误类型” to a changed next practice: “缩小问题 / 补先备 / 改用例 / 调整间隔”. The final panel branches to “可独立完成” and “仍有缺口”, both leading to a later review, with different intervals left unspecified.
- **Data and relations:** no scores, no prescribed numeric interval, no experimental performance curve. The timeline is a teaching example, not an empirical plot.
- **Source and limits:** author-created teaching synthesis. Research framing supported by [2] review and [3] prose-passage experiment as described in the chapter; do not copy or imply numerical effect sizes.
- **Textbook reading guide:** already in manuscript; readers trace the difference between first exposure, delayed retrieval and a changed task.
- **Accessibility:** distinguish phases with shapes and labels, not color only; alt text notes there is no fixed interval.

- **Visual form:** top-to-bottom evidence funnel, but use rectangular stages rather than implying that sources become inherently truer as they narrow: “确定要作出的判断（对象、版本、时间）” → “选择合适资料类型” → “定位一条具体主张” → “检查证据位置和适用条件” → “写结论与来源记录”. At the fourth stage, branch to “条件充分，可作有限结论” or “条件缺失，标为待验证并继续检索”. Add a side annotation that reposts sharing one source do not count as independent evidence.

- **Source and limits:** author-created synthesis of Section 8.3; current product/source behavior is not represented in the image.
- **Textbook reading guide:** already in manuscript; note that missing evidence sends the reader back to search instead of forcing a categorical answer.
- **Accessibility:** use explicit “有条件结论” and “待验证” labels and alt text for both branches.

## 图8-4 学习工具围绕任务形成的材料网络

- **Marker and placement:** `<!-- FIGURE:8-4 -->`; after 8.4.3 and before 8.4.4.
- **Purpose:** relate learning activity and material to possible carriers, while making clear that one can use paper/local files and need not install every product.
- **Visual form:** a three-lane map. Left lane: five task/material cards (“需要延迟回忆”, “需要追踪责任与下一步”, “需要互链的资料笔记”, “需要检查的项目文件”, “需要系统课程活动”). Middle lane: possible carriers (“纸卡 / Anki”, “纸表 / Notion”, “本地Markdown / Obsidian”, “本地Git / GitHub仓库”, “课程平台 / 教材与文档”). Right lane: observable check (“能否独立回忆”, “任务是否有负责人”, “能否找回来源”, “能否说明变更”, “能否完成课程练习”). Connect each material card to one or more alternatives. Add a footer “按权限、备份、访问条件选择；工具不是学习成果”.
- **Data and relations:** no account/pricing claims, no forced one-to-one tool assignments. Lines mean possible fit, not exclusive product capability.
- **Source and limits:** author-created task map; product capability descriptions in the text cite official documentation [4]–[9]. Do not put feature claims, current prices or account requirements in the diagram.
- **Textbook reading guide:** already in manuscript; readers follow from the target task to the carrier and then to a check of learning evidence.
- **Accessibility:** visually group by materials, not brand logos; use text labels and alt description.

## 图8-5 从外部学习节点到个人判断的反馈网络

- **Marker and placement:** `<!-- FIGURE:8-5 -->`; after 8.5.4 and before E05.
- **Purpose:** show a personal learning network as a set of functional nodes and reciprocal interactions, not a popularity graph.
- **Visual form:** learner node near the center, surrounded by five function labels: “来源 / 文档”, “同伴 / 对话”, “社区 / 复现线索”, “会议或课程 / 主题入口”, “个人练习 / 作品”. Directed arrows include question, source checking, practice feedback and contribution; return arrows lead to the learner’s own “暂定判断 / 下一步问题”. Include a dashed connection between repeated posts with a callout “追踪共同原始来源，转述不等于独立证据”.
- **Data and relations:** no follower counts, no claims that more nodes mean higher accuracy. Arrows denote possible information/feedback flow; the learner remains responsible for integration.
- **Source and limits:** author-created conceptual diagram for the chapter’s working definition of PLN; it does not present empirical network research or a universally required network topology.
- **Textbook reading guide:** already in manuscript; readers follow a question outward to a source or practice node and back to their own checked conclusion.
- **Accessibility:** use different shapes for node function and line patterns for interaction type; provide an alt text that names the routes.
