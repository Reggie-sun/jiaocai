### CLI Reference

命令在项目根目录执行；只在进入对应里程碑时使用。本次不执行这些命令。已有同 ID 的 run 必须接续，不能重复 start；恢复命令按实际状态选用。

#### start

P01首次登记；已有同id先核对状态并按恢复规则接续，不覆盖。

```bash
python3 scripts/harness.py start --id ch01-draft --spec runs/ch01-draft.spec.json
```

P08同步真实spec后检查；退出1只在报告当前失效原因并标记blocked时进入resume，其他错误停止调查。

```bash
python3 scripts/harness.py status --id ch01-draft
```

预期退出码：0、1。

#### resume

blocked/checked/reviewed需要重绑定时；不要直接对started执行resume。

```bash
python3 scripts/harness.py resume --id ch01-draft
```

预期退出码：0。

#### check

P08当前稿件与图表、材料齐备并重绑定后。


预期退出码：0。

预期退出码：0。

预期退出码：0。
